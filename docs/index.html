How to flash

  1. Plug the board into the computer with a USB data cable.
  2. Click Install for your board and pick its port in the pop-up.
  3. Tick Erase device on the first install, then wait about a minute.
  4. If it won't connect: hold the BOOT button, tap RESET, release BOOT, and try again.
  5. After flashing, open Tools → Self test on the device.

Wiring for each board is in firmware/apocalypse-comm/HARDWARE_KIT.md and README.md. Pins can only be changed by rebuilding with ESP-IDF (idf.py menuconfig).
