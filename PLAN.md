# Plan

## Goal
Browser-based ESP32 practice simulator for learners (`esp32-sim/`).

## Features
- Virtual board: LEDs, two buttons, knob, buzzer, serial monitor
- Editor + interpreter for simplified Arduino code
- 20 guided lessons with automatic checks, hints, saved progress
